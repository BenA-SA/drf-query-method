# Installation

## Stable release

To install drf-query-method, run this command in your terminal:

```sh
uv add drf-query-method
```

Or if you prefer to use `pip`:

```sh
pip install drf-query-method
```

## From source

The source files for drf-query-method can be downloaded from the [Github repo](https://github.com/BenA-SA/drf-query-method).

You can either clone the public repository:

```sh
git clone https://github.com/BenA-SA/drf-query-method
```

Or download the [tarball](https://github.com/BenA-SA/drf-query-method/tarball/main):

```sh
curl -OJL https://github.com/BenA-SA/drf-query-method/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd drf-query-method
uv sync
```
